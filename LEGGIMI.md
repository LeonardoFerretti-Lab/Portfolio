# Cartella prototipo sito – Leonardo Ferretti

Tutto il necessario per costruire il prototipo del sito portfolio con Claude Code,
preso dal profilo Behance https://www.behance.net/leonardferrett (6 progetti).

## Cosa c'è
| Percorso | Contenuto |
|---|---|
| `CLAUDE.md` | Brief per Claude Code (obiettivo, materiali, requisiti) |
| `contenuti/contenuti.md` | Tutti i testi del sito: bio, contatti, formazione, esperienze, strumenti, 9 progetti |
| `contenuti/style-guide.md` | Stile grafico nero/oro ricavato dal portfolio UX/UI, componenti e struttura pagina |
| `assets/css/tokens.css` | Colori, font (Montserrat), spaziature pronti all'uso |
| `assets/images/ux-ui/` | 7 slide del Portfolio UX/UI |
| `assets/images/illustration-portfolio/` | 9 slide del Portfolio Illustration |
| `assets/images/lezioni-americane/` | 11 immagini del libro illustrato |
| `assets/images/silvano-ferretti/` | 3 copertine |
| `assets/images/space-soda/`, `basketball/` | 1 illustrazione ciascuno |

## Come usarla con Claude Code
1. Apri un terminale in questa cartella ed esegui `claude`.
2. Scrivi: *"Leggi CLAUDE.md e crea il prototipo del sito."*
3. Apri `index.html` nel browser e chiedi le modifiche a voce.
